7 Skills de Marketing

Cómo instalar y usar las 7 skills en Claude Cowork o Claude Code

Las 7 Skills incluidas

SKILL 1

Espía de Tendencias

Monitoriza X/Twitter con Grok para encontrar tendencias de tu nicho.

SKILL 2

Scraping de Competencia

Analiza competidores en Instagram, TikTok, LinkedIn con Apify.

SKILL 3

Diseñador con Canva

Crea 10 diseños de redes de golpe con tu identidad visual.

SKILL 4

Dashboard de Negocio

Panel de control HTML con todas tus métricas en un sitio.

SKILL 5

Emails de Venta

Secuencias de 7 emails de venta listos para copiar y pegar.

SKILL 6

Auditor SEO

Informe SEO profesional de cualquier web con recomendaciones.

SKILL 7

Calendario de Contenido

Plan mensual completo con temas, títulos, hooks y formatos.

Cómo instalar las skills

Claude Cowork (fácil)
Claude Code (terminal)
Este es el método más fácil. No necesitas tocar archivos ni terminal. Solo copias y pegas en el chat de Cowork.
1

Abre Claude Cowork

Abre la aplicación de escritorio de Claude (Cowork) en tu ordenador.

2

Crea un proyecto de Marketing

En la barra lateral izquierda, crea un nuevo proyecto y llámalo "Marketing" o "Skills de Marketing".

3

Instala cada skill con un prompt

Para cada skill, simplemente escribe esto en el chat:

Crea una skill llamada "[nombre-de-la-skill]" con las siguientes instrucciones:

[Pega aquí el contenido completo del SKILL.md]

Claude creará la skill automáticamente en tu proyecto. Repite para cada una de las 7 skills.

4

Verifica

Escribe en el chat: "¿Qué skills tengo disponibles?"

Claude debería listar las 7 skills instaladas.

5

Usa las skills

Simplemente pide lo que necesitas y Claude usará la skill correcta automáticamente:

"Busca tendencias de IA esta semana"          → Skill 1
"Analiza los competidores @X @Y @Z"           → Skill 2
"Hazme 10 diseños de Instagram"               → Skill 3
"Crea un dashboard de mi negocio"             → Skill 4
"Escríbeme emails para vender mi curso"       → Skill 5
"Audita el SEO de mi web"                     → Skill 6
"Planifica mi contenido de abril"             → Skill 7
Claude detecta qué skill usar automáticamente basándose en lo que le pides. No necesitas invocarla manualmente — solo describe lo que necesitas y Claude elige la skill correcta.
Método para usuarios técnicos. Las skills se instalan como carpetas con archivos SKILL.md.
1

Crea la carpeta de skills

mkdir -p ~/.claude/skills
2

Copia las carpetas de skills

Copia cada carpeta skill-X-nombre/ dentro de ~/.claude/skills/:

cp -r skill-1-espia-tendencias ~/.claude/skills/
cp -r skill-2-scraping-competencia ~/.claude/skills/
cp -r skill-3-diseno-canva ~/.claude/skills/
cp -r skill-4-dashboard-negocio ~/.claude/skills/
cp -r skill-5-emails-venta ~/.claude/skills/
cp -r skill-6-auditor-seo ~/.claude/skills/
cp -r skill-7-calendario-contenido ~/.claude/skills/
3

Verifica la estructura

ls ~/.claude/skills/

# Deberías ver:
# skill-1-espia-tendencias/
# skill-2-scraping-competencia/
# skill-3-diseno-canva/
# skill-4-dashboard-negocio/
# skill-5-emails-venta/
# skill-6-auditor-seo/
# skill-7-calendario-contenido/

Cada carpeta debe contener un archivo SKILL.md.

4

Usa las skills

Abre Claude Code en cualquier proyecto y pide lo que necesitas. Claude detectará las skills automáticamente.

Las skills en ~/.claude/skills/ están disponibles globalmente — funcionan en cualquier proyecto que abras con Claude Code. Si quieres skills solo para un proyecto específico, ponlas en tu-proyecto/.claude/skills/.

Requisitos por skill

No todas las skills necesitan lo mismo. Aquí tienes qué necesita cada una:

Skill Funciona en Requisito extra Precio servicio
1. Espía Tendencias Solo Cowork Sesión iniciada en X (Chrome) $300/mes
2. Scraping Cowork + Code Conector Apify (gratis) $200-500
3. Diseño Canva Solo Cowork Conector Canva $150-300
4. Dashboard Cowork + Code Ninguno $300-500
5. Emails Cowork + Code Ninguno $300-800
6. SEO Cowork + Code Ninguno (usa web fetch) $300-500
7. Calendario Cowork + Code Ninguno $250-400/mes
5 de las 7 skills funcionan sin ningún requisito extra — solo necesitas Claude (Cowork o Code). Las skills 1 y 3 necesitan Cowork por los conectores visuales (X y Canva).

Tips para sacar el máximo

Combina skills. Puedes encadenar varias en una conversación: "Busca tendencias de mi nicho (Skill 1), luego genera 10 títulos basados en esas tendencias (Skill 7), y finalmente crea los diseños en Canva (Skill 3)." Claude ejecuta las tres en secuencia.
Personalízalas. Cada skill incluye preguntas de configuración. La primera vez que uses una, Claude te preguntará sobre tu negocio, nicho y estilo. Esa info se guarda en la memoria del proyecto — la próxima vez no te lo pregunta.
Véndelas como servicio. Cada skill tiene un precio de referencia al final. Usa esos precios como guía para ofrecer estos servicios a clientes. Con las 7 juntas, puedes facturar $1.850-3.500/mes por cliente.
